## 这个库是什么

别再无效自学了。打开 GitHub 搜索 **project-based-learning**，这个开源库目前已有 **264k star**。

它的核心理念是**项目式教学**：不靠理论灌输，而是以完整实战项目驱动学习。所有资源开源、永久免费，适合自学练手，也可以作为简历加分项。

## 内容覆盖

库内按技术方向精细分类，前后端、AI、游戏、底层系统开发全覆盖：

- 前端 / 后端
- AI
- 游戏开发
- 底层系统

每个方向下都是完整的实战项目，跟着做完就能掌握对应技术栈。
