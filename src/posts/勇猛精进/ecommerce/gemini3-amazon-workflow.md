## 背景

一位亚马逊卖家第一次尝试用 Gemini 3（原文写作 "Gmini3"）协同跑亚马逊店铺，感慨"后悔没有早点用 Gemini 3，少赚一个亿"。当天后台全局快照显示销售额已达 **US$55,068.64**（当日截至当时）。

这组图文同时附了一份「20 种跨境电商 AI 玩法（附真实案例）」的资料，其中完整放出的核心内容是 7 套亚马逊运营提示词模板。

## 协同工作流

从内容组织看，这套玩法把 AI 当成亚马逊运营的"协同助手"，按运营环节拆分成一个个独立任务，每个任务对应一条结构化提示词：

1. 选定任务类型（生成标题 / 优化标题 / 五点描述 / 产品描述 / QA 分析 / 用户洞察）
2. 在提示词的占位符 `[ ]` 中填入商品信息（品类、关键词、品牌、型号、特性、参数、目标人群等）
3. 统一附加同一段"要求"，约束输出质量和格式
4. 要求同时输出英文和中文版本，方便核对关键词相关性

所有提示词都遵循同一套要求模板，这是可复用的关键：

> 先提取产品卖点和特性，然后加上产品所在品类的关键词，最后优化表达，让我的[美国]客户看起来更舒服、自然。请严谨的围绕关键词展开创作，必须达到百分百的关键词相关性以及埋词率；请给我[英文]和[中文]的版本。

```
让我的[美国]客户看起来更舒服、自然。请严谨的围绕关键词展开创作，
必须达到百分百的关键词相关性以及埋词率；请给我[英文]和[中文]的版本。
```

### 6. QA 问答分析

```
我是一名亚马逊卖家，我的产品是[ABC]，我的目标市场是[美国]，请帮我从以下
类目中分析出用户最关心的产品特点，以便我更好的改进产品。

改进建议。请帮我列举 25 个问题和回答。请给我[中文]和[英文]版本。
```

### 7. 用户需求洞察

```
我是一名亚马逊卖家，我想让你帮我根据产品的品类以及销售市场进行用户洞察分析，
提供给我以下信息：

1) 用户画像：核心用户是哪些人群，他们的特点是什么；
2) 产品使用场景：产品常见的使用场景有哪些；
3) 用户痛点：用户在使用过程中有哪些问题；
4) 购买动机：用户为什么要购买这个产品；
5) 未被满足的需求：针对用户痛点，以及用户可能的需求，有哪些产品可以创新的点。

要求：请充分掌握当地消费者的心理和文化习惯，从顾客角度提供分析结果。
```

## 可复用的方法要点

- **结构化占位符**：每条提示词都用 `[ ]` 占位符留出商品信息槽位，换产品只需替换字段，不用重写指令。
- **统一的质量约束**：所有文案类任务共用同一段"要求"——先提卖点、再埋品类关键词、最后优化本地化表达，并强制要求"百分百关键词相关性和埋词率"。
- **双语输出**：每次都要求同时给出英文和中文版本，便于中文母语运营快速校验语义是否跑偏。
- **文案 + 调研两条线**：前 5 条解决 Listing 文案生产，第 6、7 条转向用户调研（QA 分析、需求洞察），让 AI 同时覆盖执行层和决策层。
