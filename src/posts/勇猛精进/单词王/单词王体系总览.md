# 单词王体系总览

本系列整理自一位网络作者（自称"青史留名"）的"**单词源于汉字**"背单词方法论语系，共约 120 期短视频转录。其核心主张只有一句话：

> 单词就是左右结构的汉字，仅此而已。

左边是**偏旁**（辅音字母组合，共 70 个），右边是**部首**（元音字母组合，约 150 组）。认识了这几百个"底层代码"，背单词就从逐字母记忆变成了像查字典一样的组合拼装。

## 六篇系统笔记

1. **[[单词王核心理论-单词就是左右结构的汉字]]** — 核心理论：单词=左右结构的"汉字"。英汉构词三层对应表、字母组合是单词的"最大公约数"、"单词源于汉字"的三层证据与"英汉本一体"论。
2. **[[单词王理论-英语是一门理科语言]]** — 数学化视角：英语是一门理科语言。排列组合观、换元思想、简单词/复杂词的定义，面向数理化好而英语差的读者。
3. **[[单词王偏旁部首体系-70偏旁与150组部首全解]]** — 偏旁部首全解：70 个偏旁清单 + 部首第 1~16 组逐组字母组合与例词。
4. **[[单词王理论-词根词缀等于自然拼读]]** — 词根词缀 = 自然拼读：核心等式的论证、通用/专用前缀速查表、两法融合使用与实战案例。
5. **[[单词王理论-音节划分与连读拼音法]]** — 音节划分与连读拼音法："正确的音节划分来源于拼写"、一元一辅接规则、拼音定位音标法、音形义一体。
6. **[[单词王实操体系-背单词方法论与实战案例]]** — 实操体系：三大基石定义、最快方法论流程、characteristic 化繁为简拆解、sentimental 三屉馒头、完整学习路径。

## 理论脉络一图流

```
26 个字母
  └─ 字母组合（底层代码）
       ├─ 辅音组合 ×70 ＝ 偏旁 ≈ 声母 ≈ 形旁（词根词缀，管含义）
       └─ 元音组合 ×150 ＝ 部首 ≈ 韵母 ≈ 声旁（自然拼读，管发音）
            └─ 偏旁 + 部首 → 左右结构拼装出上万个单词
```

三条主线在此汇合：

- **含义线**：词根词缀 = 被赋予含义的字母组合（形旁管义）
- **声音线**：自然拼读 = 被赋予声音的字母组合（声旁管音）
- **形状线**：音节划分 = 被赋予形状的字母组合（连读拼音写法）

## 如何看待这套理论

需要说明的是：**"单词源于汉字"并非主流词源学结论**——学界共识是英语词汇主要源自拉丁语、希腊语与日耳曼语系。但剥离这个溯源主张后，其方法内核（按字母组合分块记忆、形态意识教学、拼读与拼写结合）与主流认知心理学和读写教育研究（morphological awareness、phonics、onset-rime）多有吻合之处。每篇笔记末尾都附有「全网扩展」一节，将作者的个人创见与实证研究对照呈现，建议对照阅读、各取所长。
