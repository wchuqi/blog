用 Claude Code 交互式学习法一周读完了五本书——不是速读完就忘的那种，而是真正读懂并用到生活中，学习速度提升约 **5 到 10 倍**。

## 核心理念

- **带着目的去读**：先有一个问题（生活中的问题、学习科研中解决不了的难题），再为解决问题而读书
- **给书重新排序**：作者的写作顺序是普适性的，不是你吸收知识的顺序。例如《原子习惯》一到三章讲脑科学，与现实应用关系不大，完全可以先跳过读后面的实用部分，有时间再回头补

## 交互式学习的三要素

1. **学习档案**：记录学习进步和对知识的理解程度
2. **书籍骨架**：把书拆解成结构
3. **学习地图**：明确自己的学习顺序，而不是这本书的讲述顺序

这三样自己做非常耗时，最好用 Claude Code Skill 代劳。

## 实操流程（以《思考快与慢》为例）

1. 读之前让 Claude 先问你几个问题：现在的工作是什么、想解决什么问题、读这本书的目的、对这本书目前有什么理解
2. Claude 运行四个 Agent 先读完整本书，给出整体框架
3. 把书的章节按**你的问题**重排成几个单元：先用最快的方式回答你的问题，解决之后再补充其他知识
4. 每个单元配一个**苏格拉底式追问**，持续检验你是否真正理解了这个知识

学完后不仅读懂了书，还知道如何用书中思想解决你的问题。

## 适用范围

不只读书：网课、播客、论文、文献综述、会议记录——只要是可以转成文字的静态内容，都能用这个方法。

## Skill 的结构

- 主入口
- 诊断问题的模板（先问你生活中的问题）
- 书籍骨架的格式规范
- Agent 提示词模板 + 课程地图模板 + 学习单元模板（用于追问和梳理全书逻辑）
