本周 GitHub 热榜半壁江山都是 Claude Code 生态。

## Top 5

1. **Skills for Real Engineers（Matt Pocock）** —— 本周涨 2.4 万 Star，登顶榜首。给 Claude Code 写的技能文件，解决的问题：Agent 不听话、太啰嗦、代码跑不通、架构越改越烂。每个问题对应一个技能文件，按工程能力、生产力、杂项三类组织。
2. **Free Claude Code** —— 一周涨 1.6 万 Star，不花钱用 Claude Code。它做了一个代理层，把 Gemini、DeepSeek 这些 API 转成 Claude Code 能用的格式；终端、VS Code、Discord 三端都支持，选个 Provider 配好 Key 就能用。
3. **ML Intern（Hugging Face 官方出品）** —— ML 领域的自动化 Agent：读论文、写代码、训模型、发 Hugging Face 一条龙全自动。给它一篇论文，能把方法复现出来并部署上线。
4. **Carboty Skills** —— 上周讲过的项目，本周破 10 万 Star。核心就是一个 CLAUDE.md 文件，总结四大坑、四原则、对症下药。
5. **Genetic Agent** —— 自进化 Agent，Token 消耗只有同类的 1/6。从 3000 行种子代码开始，每次执行任务自己长出技能树，与 CrewAI 对比效率高很多。

## 其他值得关注

- **Claude Context**：给 Claude Code 加代码搜索能力
- **CUA（Computer Use Agent）基础设施**
- **Pixlow Video**：AI 全自动短视频
- **ds2api**：把 DeepSeek 转成通用 API

一句话总结本周生态：**Claude Code 从工具变成了平台。**
