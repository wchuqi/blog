五个 Skill 加起来近 **210 万 Star**。国外已经有人一个人开起 AI 公司——你是老板，Claude Code 是 CEO，80 个 AI 员工是团队。

## 五件套

| # | Skill | Star | 角色 |
| --- | --- | --- | --- |
| 1 | DeerFlow | 6.5 万 | **调研员**：字节出品，替你做深度调研。说一句"调研一下"，自动上网搜十几篇文章总结对比，生成一份 30 页报告 |
| 2 | Prompt Optimizer | 2.8 万 | **翻译师**：不会写 AI 指令也没关系，你说"写小红书爆款"，它自动翻译成 AI 听得懂的专业指令 |
| 3 | Agent 合集 | 3.5 万 | **80 个专业员工**：一次性给你前端工程师、数据分析师、营销专家、SEO 专家等 80 种专业角色 |
| 4 | Claude Flow（原 ruv-flow） | 4.5 万 | **总经理**：给它一个项目，它拆成十步派给不同 AI 员工分工协作、互相配合、自动验收 |
| 5 | Letta | 2.2 万 | **记忆大脑**：越用它越懂你，你的习惯和工作风格全记住，换了对话也不用从头教 |

## 关键：五件配齐

不是单独装一件就够——五件配齐才是一家完整的 AI 公司：

> 缺调研员 → 缺翻译师 → 缺 80 个员工 → 缺总经理 → 缺记忆大脑，缺一不可。

合体之后：早上你给项目，睡觉时它自动跑流程，醒来项目做完了，不用你管。
