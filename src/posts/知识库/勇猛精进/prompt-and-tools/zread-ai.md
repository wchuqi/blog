## 它是什么

Zread 是一款开源项目解析神器：只需把开源项目的网址输入到探索框里，就可以完成整个项目的解析。

## 使用步骤

1. 在 GitHub 上找到一个想了解的开源项目（例如 UI UX Pro Max 这样的前端设计工具）
2. 复制项目网址，粘贴到 Zread 的探索框里
3. 出现候选下拉列表，选择第一个即可得到解析结果

## 核心特点

### 不是简单的翻译

GitHub 上的原项目大多是纯英文界面，自己啃起来费劲，还要到处查翻译，而且文档结构是面向程序员的组织方式。Zread 会把项目解析成中文的、通俗易懂的结构——甚至小学生都能看懂，让人能顺利了解这个项目。

### Ask AI 追问细节

了解项目过程中遇到任何不懂的地方——比如关于数据库设计的、支持 AI 助手的部分——可以直接点击 Ask AI 进行追问。它内置了两个大模型：智谱的大模型和 Claude 大模型，可以针对这个项目提任何问题。

## 小结

有了 Zread 之后，可以非常轻松地掌握 GitHub 开源项目的玩法：中文解析降低阅读门槛，Ask AI 补齐细节疑问。
