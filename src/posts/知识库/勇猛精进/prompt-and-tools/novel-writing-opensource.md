## 项目概况

这是一款可以帮你轻松写出 200 万字长篇网文小说的开源项目，在 GitHub 上已经拿下 3.1k star。它基于 Claude Code 打造。

## 解决的核心痛点

它从根源上解决了所有长篇作者的两大噩梦：

- **记忆断层**
- **内容偏离**

## 关键机制

- 五维并行审查机制
- 六大执行模式
- RAG 点密度精准把控
- 分层记忆功能

通过这些机制，系统能够稳定锁定核心人设、剧情主线与伏笔铺垫，保证超长篇幅内容的一致性。

## 题材模板

系统内置了十几种主流网文题材的标准化模板，可以直接基于模板快速启动创作，大幅提升写作效率。
