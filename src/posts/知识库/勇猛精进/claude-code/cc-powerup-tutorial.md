Claude Code 上周悄悄上线了一个功能叫 `/powerup`。它不是新的 AI 能力，而是 **18 节交互式教程**，直接在终端里跑，带动画演示，把你没摸过的功能挨个展示一遍。

教程中展示的几个代表性功能：

- **Rewind（回滚）**：把整个对话状态直接回滚，跟时间穿越一样
- **Hooks**：每次 Claude Code 执行前后自动触发你写的脚本，相当于给它装了一套自定义插件系统——你说什么时候跑就什么时候跑
- **子 Agent**：一个任务拆成多个 Agent 并行跑，速度直接翻倍，你只需要等结果

18 节课覆盖从 `@` 文件引用到远程控制，全部免费，不用升级套餐。

打开终端输入 `/powerup`，看看你还差多少没开过。
